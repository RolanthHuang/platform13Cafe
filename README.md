# Platform 13｜十三號月台 · 咖啡館小時光

依照片重建的互動 3D 咖啡館。整個網站是單一檔案 `index.html`（Three.js r186，WebGPU 渲染器、WebGL2 後端），貼圖都內嵌在檔案裡，不需要其他資源。

## 部署

- **Cloudflare Pages**：上傳 `index.html`（或含它的資料夾／zip）即可。
- **本機預覽**：在 repo 根目錄執行 `python3 -m http.server`，開 <http://localhost:8000/>。

## 店貓（cats v14，2026-10-27）

三隻店貓依實際照片重新塑形，取代舊版 v13（扁平面具臉、香腸身體、灰色黑貓）。

| 貓 | 位置（視角） | 造型 |
| --- | --- | --- |
| 虎斑白 | 窗邊高桌（09 虎斑） | 棕色鯖魚紋虎斑、白口鼻與白圍兜、四隻白襪、M 字額紋與頰紋、環紋黑尾尖、黃綠眼、粉鼻；母雞蹲（趴姿、前掌向前） |
| 黑貓・薄荷綠領巾 | 橢圓桌下（10 桌下黑貓） | 全黑短毛、黃綠眼、薄荷綠花瓣領巾；側臥抬頭、前腳伸直 |
| 胖黑貓・橘色領巾 | 橢圓桌上（11 桌上黑貓） | 圓胖、黃綠眼、橘色花瓣領巾；整隻側攤 |

做法：每隻貓是一個連續的距離場（SDF）身體——頭骨、臉頰、口鼻、下巴、脖子、軀幹、大腿、四肢、腳趾、尾巴——用 block-sparse surface nets 轉成網格，逐頂點畫毛色與凹處陰影，再加上獨立的殼狀耳朵、杏仁形眼睛（會看向預設鏡頭）、鼻頭、嘴線、鬍鬚、順著毛流的細毛，以及黑貓的花瓣 scrunchie 領巾。網格在載入時即時生成，每隻約 1–2 秒。

與舊版相比（同一個無頭瀏覽器、軟體算繪實測）：

| | 舊版 v15 | 新版 |
| --- | --- | --- |
| 載入到可操作 | 139 秒 | 21 秒 |
| 場景三角面 | 990 萬 | 565 萬 |
| 檔案大小 | 20.4 MB | 14.6 MB（移除已不使用的虎斑毛皮照片） |

`window.cafe.getState().cats` 會回報每隻貓的 `detailVersion: 14`、姿勢與領巾顏色。

## 檔案

- `index.html`：可直接部署的完整網站。
- `cats/cat-kit.js`：店貓的可讀原始碼，與 `index.html` 內嵌的是同一份。
- `cats/bench.html`：只看三隻貓的檢視頁，可旋轉縮放。需要用 http 伺服器開啟，例如 <http://localhost:8000/cats/bench.html>。
- `tools/update-cats.py`：改完 `cats/cat-kit.js` 後執行 `python3 tools/update-cats.py`，把新版塞回 `index.html`（取代 `P13 CAT KIT BEGIN/END` 兩個標記之間的內容）。
